# MAP — Missing AI Patterns

MAP is an open, framework-agnostic knowledge base of production-oriented AI
engineering patterns, together with the tooling and website that consume it.

This repository is the canonical home of the complete MAP project:

| Directory | Contents |
| --- | --- |
| [`patterns/`](patterns/) | Pattern catalog, specifications, examples, and reference implementations |
| [`sdk/`](sdk/) | MAP CLI and shared TypeScript packages |
| [`website/`](website/) | Registry-fed MAP website |
| [`.map/`](.map/) | MAP workspace metadata |

Start with the [pattern catalog](patterns/README.md), install the
[`@missing-ai-patterns/cli`](sdk/packages/cli/README.md), or read the
[project roadmap](patterns/ROADMAP.md).

The original repositories were consolidated here with their Git histories.
